Estrutura Básica

Toda página web precisa de uma estrutura mínima padrão para que os navegadores saibam interpretá-la corretamente:

<!DOCTYPE html>: informa ao navegador e a outros dispositivos qual é a versão de marcação em que o código foi escrito.

<html lang="pt-br">: html é a tag raiz do código. O atributo lang="pt-br" define o idioma principal da página (lang vem de language).

<head>: área onde colocamos informações que servem para os dispositivos e navegadores lerem. Não é visível na tela.

<meta charset="UTF-8">: garante a acentuação correta e o suporte a caracteres especiais. UTF-8 é a mais utilizada atualmente.

<title>: define o título que aparece na aba do navegador e nos resultados de busca.

<body>: é a parte visível da página. Tudo o que colocamos aqui (textos, imagens, formulários, vídeos) aparece diretamente no corpo do site.

Títulos

Hierarquia de Títulos (h1 até h6)

Os títulos vão do maior (h1) até o menor (h6) para organizar a estrutura da página.

H1: Este é o título principal.
H2: Este é o subtítulo.
H3: Este é o título de nível 3.
H4: Este é o título de nível 4.
H5: Este é o título de nível 5.
H6: Este é o título de nível 6 (menor nível).

Listas Ordenadas e não Ordenadas

Exemplo de listas ordenadas (enumeradas):

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

Exemplo de listas não ordenadas (marcadores):

  • Primeiro item
  • Segundo item
  • Terceiro item

Para diferenciar a lista ordenada da não ordenada, utilize a tag <ol> para listas ordenadas e <ul> para listas não ordenadas.

Seguindo de <li> para cada item da lista.

Na prática ficaria assim:

Para listas ordenadas:

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
</ol>

Para listas não ordenadas:

<ul>
  <li>Item A</li>
  <li>Item B</li>
</ul>

Links e Mídias

Links

Para direcionar o usuário para outras páginas ou seções, usamos a tag <a> (anchor / âncora):

<a href="https://www.exemplo.com" target="_blank">Link externo</a>

href: Atributo que define para onde o link vai apontar.

target: Define onde o link deve abrir:

  • _blank: abre em uma nova aba;
  • _self: abre na mesma aba (padrão);
  • _parent: abre na aba pai;
  • _top: abre na aba principal.

title: Mostra um pequeno balão informativo quando o usuário passa o mouse por cima do link.

Mídias

Imagens

Para inserir imagens, usamos a tag <img>:

<img src="imagens/exemplo.jpg" alt="Descrição da imagem">

src: Atributo que define o caminho da imagem.

alt: Texto alternativo que descreve a imagem, importante para acessibilidade e SEO.

Vídeos

Para inserir vídeos, usamos a tag <video>:

<video src="videos/exemplo.mp4" controls></video>

controls: Atributo que adiciona controles de reprodução ao vídeo.

Áudio

Para inserir áudio, usamos a tag <audio>:

<audio src="audios/exemplo.mp3" controls></audio>

controls: Atributo que adiciona controles de reprodução ao áudio.

Track

Para adicionar legendas a vídeos, usamos a tag <track>:

<video src="videos/exemplo.mp4" controls>
  <track src="legendas/exemplo.vtt" kind="subtitles" srclang="pt" label="Português">
</video>

kind: Define o tipo de legenda (subtitles, captions, descriptions, chapters, metadata).

srclang: Define o idioma da legenda.

label: Define o rótulo da legenda que será exibido no player.

IFrames

Para inserir conteúdo de outras páginas, usamos a tag <iframe>:

<iframe src="https://www.exemplo.com" width="600" height="400"></iframe>

width: Define a largura do iframe.

height: Define a altura do iframe.

Formulários

Os formulários permitem coletar dados dos usuários de forma interativa. A tag principal é <form>.

Exemplo de formulário:







Esse é um exemplo do código de um formulário em HTML:

<form action="/enviar" method="post">
  <label for="name">Nome:</label>
  <input type="text" id="name" name="name" required>
  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email" required>
  <label for="mensagem">Mensagem:</label>
  <textarea id="mensagem" name="mensagem" rows="4" cols="50" required>
  <input type="submit" value="Enviar">
</form>

O atributo name define o nome do campo que será enviado ao servidor.

O atributo action define para onde os dados do formulário serão enviados.

O atributo method especifica o método de envio dos dados do formulário.

  • GET: envia os dados anexados à URL, visível na barra de endereços;
  • POST: envia os dados no corpo da requisição, não visível na barra de endereços.

O atributo autocomplete define se o navegador deve completar automaticamente o campo.

  • on: permite que o navegador sugira e complete automaticamente os campos;
  • off: desativa a sugestão e o preenchimento automático dos campos.

Inputs

Os inputs são os campos de entrada de dados do formulário. Alguns tipos de input:

  • text: campo de texto;
  • email: campo de e-mail;
  • password: campo de senha;
  • number: campo de número;
  • date: campo de data;
  • checkbox: caixa de seleção;
  • radio: botão de opção;
  • submit: botão de envio;
  • reset: botão de reset;
  • file: campo de upload de arquivo;
  • color: campo de seleção de cor;
  • range: campo de seleção de intervalo;
  • url: campo de URL;
  • tel: campo de telefone;
  • search: campo de pesquisa;
  • time: campo de hora;
  • month: campo de mês;
  • week: campo de semana;

Tabelas

As tabelas servem para organizar dados complexos em linhas e colunas estruturadas.

Exemplo de tabela:

Nome Idade Cidade
João 25 São Paulo

Esse é um exemplo do código de uma tabela em HTML:

<table border="1" cellpadding="8" cellspacing="0">
  <thead>
    <tr>
     <th>Nome</th>
     <th>Idade</th>
     <th>Cidade</th>
    </tr>
  </thead>
  <tbody>
    <tr>
     <td>João</td>
     <td>25</td>
     <td>São Paulo</td>
    </tr>
  </tbody>
</table>

Para organizar dados em uma tabela, utilizamos as tags <table>, <thead>, <tbody>, <tfoot>, <tr>, <th> e <td>.

thead - Define o cabeçalho da tabela.

tbody - Define o corpo da tabela.

tfoot - Define o rodapé da tabela.

tr - Define uma linha da tabela.

th - Define uma célula de cabeçalho.

td - Define uma célula de dados.
