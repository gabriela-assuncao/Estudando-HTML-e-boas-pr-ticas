📚 Guia Prático e Portfólio de Estudos HTML5

Este repositório contém um guia completo, didático e prático sobre HTML5, construído com base em anotações de aulas e desafios de projetos práticos. O objetivo é servir como um manual de referência para iniciantes e documentar a evolução dos estudos em desenvolvimento web.

🚀 Sobre o Projeto

O projeto consiste em uma página web construida 100% em HTML, que aplica todos os conceitos fundamentais do HTML5 sem a necessidade de frameworks externos. A página funciona como um tutorial explicativo que aborda desde a estrutura básica de um arquivo HTML até a criação de formulários complexos, tabelas e inclusão de mídias.
